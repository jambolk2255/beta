A plugin to register custom user roles and capabilities for My WebApp.

== Description ==

This plugin registers the following custom roles:
* My WebApp Admin
* My WebApp Moderator
* My WebApp Instructor
* My WebApp User

It assigns specific capabilities to each role tailored for the My WebApp platform.

== Installation ==

1. Upload the `my-webapp` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Roles will be created upon activation.

== Frequently Asked Questions ==

= What happens if I deactivate the plugin? =
The custom roles will be removed.

= What happens if I delete the plugin? =
The custom roles will be removed by the `uninstall.php` script.
